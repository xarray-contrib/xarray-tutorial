# Hierarchical Datasets Path

Use this path when your data is organized into related groups that do not fit
in a single `Dataset`. It assumes you are comfortable with labeled dimensions,
coordinates, and datasets from the {doc}`../fundamental-path/README`.

1. {doc}`Organize datasets with DataTree <../../fundamentals/01_datatree_hierarchical_data>`:
   learn how to navigate groups and work with their coordinates.
2. {doc}`Compute across a hierarchy <../../intermediate/computation/hierarchical_computation>`:
   apply computations to the datasets in a tree.
3. {doc}`Open hierarchical Zarr stores <../../intermediate/hierarchical_zarr_store>`:
   see how a hierarchy of groups in storage maps to a `DataTree`.
